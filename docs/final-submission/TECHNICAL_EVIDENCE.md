| Area | Implemented design and local evidence |
|---|---|
| Architecture | JavaScript and Vite widget with Leaflet, Express API on Node 24. Deterministic academic and institutional services run alongside semantic planning and bounded generation. Answer Sources are optional disclosures. |
| Storage | Isolated preview uses SQLite in memory, temporary synthetic profiles and local JSON knowledge. Hosted configuration expects PostgreSQL, durable knowledge records and private object storage. |

| Support and tutoring | Ticket intake, ownership checks, confirmation before submission, staff queues and replies, eligible peer tutoring and student discovery controls. The repository includes isolated workflow tests. |
| Notifications | Student notifications, reminders and daily briefs are implemented, protected by student access and scoped to relevant records or timetable contexts. |
| Voice and appearance | Browser-native speech recognition and read-aloud; user verified microphone input and accepted the repaired controls. The browser verified Listen, Stop and replay transitions. No institutional adoption, interviews, survey results, or group contributions were inferred.
