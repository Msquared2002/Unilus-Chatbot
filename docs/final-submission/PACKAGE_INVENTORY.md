# Package inventory

Run the packaging script from the integration checkout. The internal PACKAGE_MANIFEST.json lists each archived input. Included categories are backend and widget source, checked-in manifests and locks, migrations, fixtures, campus geometry and data, local timetable and catalogue data, vectors and chunks, eligible frontend assets, local launch scripts and reports.

The packager excludes the demo auth database, private environment files, SQLite files, uploads, dependencies, backup files and videos. A signature scan stops on candidate credential material without printing matches. Inspect redistributable university material, photos and avatar licences before distribution. No permission or ownership is inferred from a file being present.
