# Campus integration

Silverest continues to use the existing canonical spatial API and its 23 browser-observed places. Pioneer adds five OSM-derived footprints, five approximate anchors and 48 directory records. Its 31 room records include 14 ground-floor and 17 first-floor entries. Room 17 is the computer lab, Room 19 is Sick Bay and Room 21 is Enquiries and IT. The short and long wings are directory descriptions. Any conflict with published timetables concerns usage and has no effect on source venue or class records.

Leopards Hill adds 12 footprint polygons, three service lines, an adjacent school reference, and 20 directory records. Parking has an approximate anchor. Old and New Building floor and room associations are reported as directory facts. Their physical polygons and exact room positions are unconfirmed. Room 7 and exam hall records preserve historical qualifiers.

The importer uses public OpenStreetMap geometry under ODbL and directory facts supplied in the campus handoff. Private annotated imagery was excluded. The maps retain Esri tile attribution. Routes and travel times for the new campuses require verified walking networks.
